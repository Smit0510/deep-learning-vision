# Deep Learning: Computer Vision Portfolio

This repository houses my projects in Computer Vision, applying Deep Learning architectures to image classification tasks.

## Projects Included
* **Actor Classification:** A CNN-based model to classify images of actors.
* **Flower Classification:** Image recognition model identifying different species of flowers using neural networks.

## Tech Stack
* **Languages:** Python
* **Libraries:** TensorFlow/Keras, OpenCV, NumPy, Matplotlib
* **Tools:** Jupyter Notebook

## Technical Notes
- Project outputs have been cleared to ensure repository performance.
- These projects demonstrate core skills in building Convolutional Neural Networks (CNNs), image preprocessing, and model evaluation in visual recognition tasks.
